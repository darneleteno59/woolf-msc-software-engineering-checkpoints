# Answers

## 1. How does the web works ?

    The web works through communication between a client and a server. 
    When a user enters a URL in a browser, the browser sends an HTTP 
    request to a web server. The server processes the request and sends 
    back a response, usually HTML, CSS, JavaScript, images, or data. The 
    browser then renders this content so the user can interact with the website.

## 2. What do you need to be a web developer ?

    To become a web developer, you need:
        ● A good understanding of HTML, CSS, and JavaScript.
        ● Knowledge of a frontend framework such as React or Next.js.
        ● Knowledge of backend technologies such as Node.js and Express.
        ● Understanding of databases such as PostgreSQL or MongoDB.
        ● Familiarity with version control tools like Git and GitHub.
        ● Problem-solving skills, logical thinking, and continuous learning.
